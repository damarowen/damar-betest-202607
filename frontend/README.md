# Damar Backend Betest - Frontend

Vite + React + TypeScript frontend for User Management.

## Requirements

- Node.js 20+
- Backend API running

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

## Available Scripts

- `npm run dev` - Development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm test` - Run unit tests

## Tech Stack

- Vite
- React 18 + TypeScript
- Redux Toolkit + Redux Thunk + Redux Saga
- React Router v6
- Tailwind CSS
- React Hook Form
- Axios
