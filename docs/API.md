# API Documentation

## Auth Endpoints

### POST /api/auth/login
Generate JWT token.

**Body:**
```json
{
  "userName": "damar",
  "password": "password123"
}
```

**Response:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs..."
}
```

## User Info Endpoints

All endpoints require `Authorization: Bearer <token>` header.

### GET /api/user-infos
List users with optional filter and sort. Returns enriched data with `accountId` and `lastLoginDateTime` from account-logins.

**Query Parameters:**
- `fullName` (string, optional) - Filter by full name (case-insensitive regex)
- `role` (string, optional) - Filter by role
- `sort` (string, optional) - Sort field, prefix with `-` for descending
- `page` (number, optional) - Page number, default 1
- `limit` (number, optional) - Items per page, default 10

**Response:**
```json
{
  "data": [
    {
      "_id": "507f1f77bcf86cd799439011",
      "fullName": "Damar Owen",
      "accountNumber": "100000001",
      "emailAddress": "damar@example.com",
      "registrationNumber": "REG-2024-0001",
      "role": "admin",
      "accountId": "acc-001",
      "lastLoginDateTime": "2026-08-08T10:00:00.000Z"
    }
  ],
  "total": 1
}
```

### GET /api/user-infos/:id
Get user detail by MongoDB `_id`.

### GET /api/user-infos/account-number/:accountNumber
Get user by accountNumber.

### GET /api/user-infos/registration-number/:registrationNumber
Get user by registrationNumber.

### POST /api/user-infos
Create new user. `_id` is auto-generated by MongoDB.

**Body:**
```json
{
  "fullName": "Damar Owen",
  "accountNumber": "100000001",
  "emailAddress": "damar@example.com",
  "registrationNumber": "REG-2024-0001",
  "role": "admin"
}
```

### PUT /api/user-infos/:id
Update user by MongoDB `_id`.

### DELETE /api/user-infos/:id
Delete user by MongoDB `_id`.

## Account Login Endpoints

All endpoints require `Authorization: Bearer <token>` header.

### GET /api/account-logins
List account logins with filter and sort.

### GET /api/account-logins/inactive
Get account logins with lastLoginDateTime older than 3 days.

### GET /api/account-logins/:accountId
Get account login detail.

### POST /api/account-logins
Create new account login.

**Body:**
```json
{
  "accountId": "acc-001",
  "userName": "damar",
  "password": "password123",
  "userInfoId": "507f1f77bcf86cd799439011"
}
```

### PUT /api/account-logins/:accountId
Update account login.

### DELETE /api/account-logins/:accountId
Delete account login.
